# Field_Service_HF_Mail (EN)

A simple module that adapts the sign wizard from fieldservice 18.0 to 16.0 and adds a wizard to email service orders.

# Field_Service_HF_Mail (ES)

Un module simple que adapta el wizard de firmas del modulo fieldservice 18.0 a 16.0 y agrega un wizard para enviar emails de una orden de servicio especifica.
